# Clipping

Alles staat in de map [`clipping/`](clipping/): een auto-clip tool die van een lange video korte, 9:16 clips met captions maakt, volgens de regels van een campagne.

    cd clipping
    pip install -r requirements.txt
    python clip.py video.mp4 --rules brief.pdf

Zie [`clipping/README.md`](clipping/README.md) voor alle uitleg.
